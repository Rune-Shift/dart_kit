# konsumer_core

#### A small set of widgets that brings Bloc-like builder and listener patterns to Riverpod, while keeping the flexibility and capabilities of Riverpod.
#### Build UI from a Riverpod notifier, react to state changes, and run logic after the widget’s first frame — all through a simple widget API.

### Why?

#### Riverpod gives you a lot of flexibility when consuming state, but applications sometimes benefit from a more structured widget pattern.
